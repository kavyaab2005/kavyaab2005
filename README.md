### 📌 Featured Projects

#### 🏠 SmartEstate AI: AI-Powered Real Estate Platform

A full-stack platform where buyers search and compare listings on a map, chat with an AI assistant and get AI-generated insight on every property, while listings are checked for fraud and verified through their documents.

- 🔎 Property search with filters, map view, comparison and favorites
- 🤖 RAG chatbot over live listings (sentence-transformers, ChromaDB, Groq)
- 📈 ML price prediction, price forecasting, fraud and duplicate-listing detection
- 📄 OCR document verification with a trust score and admin review
- 📍 Location intelligence, sustainability estimate and EMI calculator
- 🧱 50+ REST endpoints, built entirely on free-tier services

**Stack:** FastAPI • PostgreSQL • React • Vite • Tailwind CSS • ChromaDB • Groq • sentence-transformers • XGBoost • Tesseract OCR

🔗 [GitHub](https://github.com/kavyaab2005/smart-estate-ai)

<br>

#### 🧠 LLM Fine-Tuning: Medical Q&A Assistant

Fine-tuned Mistral-7B on medical Q&A and deployed it as a live demo.

- 📚 Trained on 2,000 medical Q&A samples using QLoRA (4-bit) with Unsloth on a free T4 GPU
- ⚙️ LoRA rank-8 reduced the trainable parameters to just 0.58%
- 🚀 Deployed on HuggingFace Spaces with a Gradio interface

**Stack:** Mistral-7B • QLoRA • Unsloth • PEFT • TRL • Gradio • HuggingFace

🔗 [GitHub](https://github.com/kavyaab2005/medical-llm-finetuning) • [Demo](https://huggingface.co/spaces/kavya-17b/medical-chatdoctor-demo)

<br>

#### 📄 RAG-Based Document Q&A Chatbot

An end-to-end RAG pipeline: upload a PDF or TXT file and get AI-powered answers with source citations.

- ✂️ Vector ingestion with chunk size 1000 and overlap 200
- 📎 Every answer comes with source citations
- 🚀 Deployed on Streamlit Cloud with CI/CD

**Stack:** LangChain • ChromaDB • Groq LLM • Gemini Embeddings • Streamlit

🔗 [GitHub](https://github.com/kavyaab2005/rag-chatbot) • [Demo](https://rag-chatbot-kkega75mx9sfmx8m3oq9xt.streamlit.app)
